# 사용 환경 정리

## Frontend

- Framework: React Native 0.81.5, expo 54
- Env file: `Frontend/native/.env`
- API base URL env: `EXPO_PUBLIC_API_BASE_URL`

설치/실행:

```bash
cd Frontend/native
npm install
npx expo start
```



## Backend

- **JDK:** OpenJDK 21.0.9
- **JVM:** OpenJDK 64-Bit Server VM
- **Spring Boot:** 3.5.11

> 확인 명령어

```bash
java -version
```

## AI

- **Python:** `python3` 환경 사용
- **패키지:** `requirements-server.txt`
- **실행 엔트리:**
  - AI 분석 서버: `chatbot.py`
  - 업로드 전처리 서버: `analysis/demo_app.py`

- **기본 포트:**
  - AI 분석 서버: `8000`
  - 업로드 전처리 서버: `5000`

> 설치/실행

- 로컬 실행:

```bash
cd ai_repo
python3 -m venv .venv --system-site-packages
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements-server.txt

# AI 분석 서버
python chatbot.py

# 업로드 전처리 서버
python -c "from analysis.demo_app import run_demo_server; run_demo_server(host='0.0.0.0', port=5000, debug=False)"

## 환경 변수

### Database(AWS RDS PostgreSQL) Configuration

- DB_URL=JDBC URL
- DB_USERNAME=DB 유저 이름
- DB_PASSWORD=DB 유저 비밀번호

### Redis(Elasticache) Configuration

- REDIS_HOST=Redis 호스트
- REDIS_PORT=Redis 포트

### S3

- AWS_S3_ACCESS_KEY=AWS S3 접근을 위한 액세스 키 ID
- AWS_S3_SECRET_KEY=AWS S3 접근을 위한 시크릿 액세스 키
- AWS_S3_BUCKET=AWS S3 접근을 위한 버킷 이름

### SSAFY Login API

- SSO_SSAFY_CLIENT_ID=SSAFY 로그인 API 어플리케이션 등록 시 발급받는 ID
- SSO_SSAFY_CLIENT_SECRET=SSAFY 로그인 토큰 발급 시 보안 강화를 위한 추가 확인 코드
- SSO_SSAFY_REDIRECT_URI=전달받을 서비스 서버 URI

### SOLAPI(핸드폰 인증)

- SOLAPI_API_KEY=API 공개 식별자
- SOLAPI_API_SECRET=비밀 서명 키
- SOLAPI_SENDER=sender 번호

### Front

- EXPO_PUBLIC_API_BASE_URL=https://j14d106.p.ssafy.io
- CLOSETORY_BASE_URL=앱에서 API 요청을 보낼 서버 Base URL
- X_ACCESS_TOKEN=액세스 토큰을 담는 HTTP 헤더 이름
- X_REFRESH_TOKEN=리프레시 토큰을 담는 HTTP 헤더 이름
- USERID=사용자 ID를 전달/저장할 때 사용하는 키 이름
- SHARED_PREFERENCES_NAME=앱에서 사용하는 SharedPreferences 파일 이름
- COOKIES_KEY_NAME=쿠키를 SharedPreferences에 저장할 때 쓰는 key 이름

### AI

- GMS_KEY=사용하는 GMS key
- CATEGORY_LLM_ENABLED=1
- CATEGORY_LLM_MODEL=gpt-5.2 (모델명)
- CATEGORY_LLM_TIMEOUT_SEC=20
- CATEGORY_LLM_BASE_URL=https://gms.ssafy.io/gmsapi/api.openai.com/v1
