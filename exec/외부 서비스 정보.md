# WoW 외부 서비스 정보

## 개요

본 문서는 WoW 프로젝트에서 사용하는 외부 서비스 정보를 정리합니다.
AI 생성 정보, 이미지 저장, 캐시/토큰 관리 등을 위해 필요한 정보를 포함합니다.

## 1. AI 서비스

### 1.1 Flask AI Server

- **서비스 용도**: 소비 거래 전처리, 소비 유형 예측, AI 소비 피드백
- **연동 방식**: Spring Boot → Flask HTTP 호출
- **서비스 클래스**: `SpendingServiceImpl.java`
- **주요 엔드포인트**:
  - `POST /api/preprocess-transactions` : 은행/카드 CSV 업로드 → 가맹점 카테고리 분류
  - `POST /api/predict` : GMM 모델로 소비 유형 클러스터 예측
  - `POST /api/advise` : Qwen2.5-14B AI 소비 분석 피드백 생성
  - `GET /api/overrides` : 가맹점 카테고리 오버라이드 목록 조회
  - `POST /api/overrides` : 가맹점 카테고리 오버라이드 저장

### 1.2 Runpod AI Server

- **서비스 용도**: AI 소비 분석 피드백 생성
- **연동 방식**: Flask → RunPod HTTP 호출
- **사용 모델**: Qwen2.5-14B

### 1.3 GPT API 

- **서비스 용도**: 가맹점 카테고리 자동 분류
- **연동 방식**: Flask → GMS 프록시 경유 → GPT API 호출
- **사용 모델**: Gpt5.2
